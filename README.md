# Customer Churn Analysis

## Identifying High-Risk Customers and Churn Drivers

## 📊 Power BI Dashboard



### Project Overview

This project analyzes customer churn by combining customer, subscription, and support data. The goal is to identify churn patterns, high-risk customer segments, and factors associated with customer churn.

### Project Objectives

- Analyze overall customer churn and retention.
- Identify customer segments with higher churn.
- Analyze churn by subscription plan and location.
- Identify factors associated with customer churn.
- Analyze support escalations and their relationship with churn.
- Identify high-risk customers for potential retention efforts.

### Tools Used

- Python
- Pandas
- NumPy
- SQLite
- Matplotlib
- Seaborn
